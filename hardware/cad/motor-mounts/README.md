# Motor mount CAD

Keep motor mounting designs and manufacturing exports here.

The project has two distinct motor roles:

- NEMA 23 stepper motor with TB6600 driver for the drive system.
- NEMA 17 stepper motor used in the separate gear-driven steering mechanism.

For each mount, record the motor model, mounting-hole spacing, shaft centre height, material, thickness, fasteners, and load assumptions. Check shaft alignment, gear engagement, belt or coupling clearance, and access for maintenance.
