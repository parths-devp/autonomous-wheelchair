# Assembly CAD

This directory is reserved for the complete wheelchair assembly and its subassemblies.

## Suggested contents

- Native CAD assembly file.
- Neutral STEP export.
- Exploded assembly view.
- Bill of materials linked to the component list.
- Assembly drawings with fastener sizes and critical dimensions.

Keep the steering mechanism, drive motor, motor mounts, chassis, and sensor brackets as identifiable components. Use consistent component names and units.

No complete assembly CAD file has been committed yet. Add files only after checking that component positions, joint constraints, clearances, and fastener access match the physical prototype.
