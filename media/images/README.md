# Images

Store project photographs, CAD renders, wiring photographs, and annotated test images here.

Suggested folders:

- `hardware/` — chassis, steering, motor, sensor mounting, and electronics.
- `software/` — detection screenshots, GUI output, and calibration captures selected for reports.
- `testing/` — controlled test setup and obstacle scenarios.

Use descriptive filenames with dates and short captions. Avoid committing duplicate images, temporary screenshots, or photographs containing personal information without permission. Calibration source images should remain in the calibration workflow rather than being mixed with presentation media.
