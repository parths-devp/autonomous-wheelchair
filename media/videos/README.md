# Videos

Store short project demonstrations or links to hosted videos here.

Useful demonstrations include:

- YOLO11n person detection on the Raspberry Pi.
- HC-SR04 readings for front, left, and right sensors.
- Arduino forward, backward, and stop commands with wheels raised.
- Obstacle stop and automatic forward resume in a controlled test area.
- Full prototype operation with an observer and emergency stop available.

For each video, record the software revision, hardware configuration, test conditions, and whether the test was supervised. Do not present a subsystem demonstration as proof that the complete wheelchair is safe for independent use.
